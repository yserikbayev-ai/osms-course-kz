# CLAUDE.md — как работать с этим репозиторием

Платформа обучения медперсонала нормативным правовым актам РК (ОСМС, правила
финансирования ПМСП). Весь материал выведен из действующих приказов МЗ РК:
каждый урок и каждый вопрос привязан к пункту конкретного акта.

Подробности замысла и правила контента — в `SPEC.md`, обзор курсов — в `README.md`.

## Устройство: где правда

Сайт — одна статическая страница, без бэкенда и без зависимостей.

```
source/*.js  →  source/build.sh  →  index.html (корень) = то, что видит пользователь
```

`index.html` **собран**, руками его не правят. GitHub Pages отдаёт именно его,
поэтому push в `main` — это и есть публикация.

| Где | Что |
|---|---|
| `source/taxonomy.js` | направления, курсы, порядок |
| `source/content_*.js` | нормы, уроки и вопросы по темам |
| `source/app_*.js`, `app_style*` | логика и оформление платформы |
| `source/build.sh` | сборка одного файла из всего перечисленного |

## Порядок правки — важное

1. Правишь **только** файлы в `source/`.
2. Пересобираешь и обновляешь корневой файл:
   ```bash
   bash source/build.sh && cp source/index2.html index.html
   ```
3. Проверяешь:
   ```bash
   bash source/check.sh
   ```

`check.sh` смотрит синтаксис исходников и сверяет собранное с `index.html`.
Забыли пересобрать — проверка красная: правка иначе просто не доедет до сайта.

## Правила контента (из SPEC.md, раздел 3.5)

Вопрос не публикуется, если выполнено хотя бы одно:

- нет привязки к конкретной норме;
- верных ответов не ровно один;
- варианты дублируют друг друга;
- вопрос проверяет номер или дату акта вместо содержания;
- ответ не выводится из текста привязанной нормы.

**Ничего не додумывать.** Норма, которой нет в приложенном акте, в курс не
попадает — ни как факт, ни как вариант ответа. Если для правки не хватает
первоисточника, честно скажите об этом, а не пересказывайте по памяти.

## Чего не делать

- Не править `index.html` руками — при следующей сборке правка исчезнет.
- Не переписывать `SPEC.md` заодно с задачей: это решение владельца.
- Не добавлять зависимости, сборщики и фреймворки: страница намеренно
  открывается без установки чего бы то ни было.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
