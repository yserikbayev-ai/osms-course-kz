# Курс ОСМС — обучение медперсонала по НПА РК

Прототип системы обучения медицинского персонала нормативным правовым актам
Республики Казахстан. Первая тема — **обязательное социальное медицинское
страхование (ОСМС) и правила финансирования ПМСП**.

**Демо:** https://yserikbayev-ai.github.io/osms-course-kz/

---

## Что это

Учебный курс, содержимое которого целиком выведено из действующих приказов
Министерства здравоохранения РК. Каждый урок и каждый вопрос привязан к
конкретному пункту конкретного акта, с цитатой нормы и ссылкой на первоисточник
в государственной информационно-правовой системе «Әділет».

### Устройство курса

Три грейда с последовательным допуском — следующий открывается только после сдачи
предыдущего:

| Грейд | Что проверяет | Экзамен | Порог |
|---|---|---|---|
| Базовый | Знание нормы: что положено, кому, кем оказывается | 20 вопросов / 30 мин | 80 % |
| Продвинутый | Применение нормы в практической ситуации | 25 вопросов / 40 мин | 80 % |
| Экспертный | Дефекты, снятие оплаты Фондом, пересечение норм | 30 вопросов / 50 мин | 80 % |

**9 уроков · 54 нормы · 105 вопросов.** Вопросы и варианты ответов перемешиваются
при каждой попытке.

### Цикл корректирующих действий

Ядро продукта — не факт сдачи, а измеримое улучшение:

```
Тест → Корректирующие действия → Повторный тест → Прогресс
```

При неудачной попытке система определяет нормы, по которым допущены ошибки, и
назначает повторение **только соответствующих уроков** — не курса целиком.
Повторный экзамен заблокирован, пока корректирующие действия не отмечены
выполненными. После пересдачи показывается дельта в процентных пунктах — она же
главная метрика в отчёте руководителя.

### Контроль качества вопросов

Вопросы сгенерированы автоматически из текстов актов. Каждый обязан нести привязку
к норме, иначе не публикуется. У обучающегося есть кнопка «Оспорить вопрос»: после
трёх жалоб вопрос автоматически замораживается и перестаёт выдаваться до разбора.

## Нормативная база курса

| Акт | Реквизиты |
|---|---|
| Правила ведения учёта потребителей медуслуг и предоставления права на медпомощь в системе ОСМС | № ҚР ДСМ-333/2020 от 29.12.2020 |
| Правила прикрепления физических лиц к организациям ПМСП | № ҚР ДСМ-194/2020 от 13.11.2020 |
| Правила оказания первичной медико-санитарной помощи | № ҚР ДСМ-90 от 24.08.2021 |
| Стандарт организации оказания ПМСП в Республике Казахстан | № 49 от 30.03.2023 |
| Правила проведения мониторинга исполнения условий договора закупа медуслуг | № ҚР ДСМ-321/2020 от 24.12.2020 |

Акты отобраны из полной выгрузки 2479 нормативных правовых актов Минздрава РК
(состояние ИПС «Әділет» на 01.08.2026).

## Структура репозитория

```
index.html      — приложение целиком, один самодостаточный файл
source/         — исходники: контент по грейдам, логика, стили
```

Приложение не требует сборки и работает без сервера: достаточно открыть
`index.html`. Прогресс хранится в localStorage браузера.

## Границы прототипа

Это проверка концепции, а не готовый продукт. Сознательно отсутствуют:

- серверная часть — нет учётных записей, прогресс живёт только в браузере;
- разделение по клиникам (мульти-арендность) и роли пользователей;
- Telegram-напоминания;
- еженедельный монитор изменений в «Әділет» с перегенерацией затронутых вопросов.

Показатели руководителя, кроме собственной строки пользователя, — демонстрационные.

Полная архитектура описана в [SPEC.md](SPEC.md).

## Оговорка

Тексты норм соответствуют состоянию ИПС «Әділет» на дату выгрузки. Материал носит
учебный характер; для юридически значимых решений сверяйтесь с первоисточником по
ссылкам, приведённым в каждом уроке.
