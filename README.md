# Обучение медперсонала по НПА РК

Платформа обучения медицинского персонала нормативным правовым актам Республики
Казахстан. Материал курсов целиком выведен из действующих приказов Министерства
здравоохранения РК: каждый урок и каждый вопрос привязан к конкретному пункту
конкретного акта со ссылкой на первоисточник в ИПС «Әділет».

**Демо:** https://yserikbayev-ai.github.io/osms-course-kz/

---

## Структура: направления деятельности

Обучение разделено по направлениям работы медицинской организации. Внутри
направления курсы выстроены в рекомендованном порядке — но это подсказка маршрута,
а не блокировка: **любой курс доступен в любой момент**.

| Направление | Курсы |
|---|---|
| Прикрепление населения | Прикрепление к организации ПМСП |
| Участковая служба | Участок и работа на дому · Приём пациента: документация и маршрутизация |
| Вакцинация | Профилактические прививки: организация и допуск |
| Профилактические осмотры и скрининги | Профилактические осмотры целевых групп · Скрининговые исследования |
| Диспансерное наблюдение | Динамическое наблюдение |
| ОСМС и финансирование | Право на медпомощь в ОСМС · Лекарственное обеспечение · Мониторинг Фонда |

**6 направлений · 10 курсов · 15 уроков · 140 вопросов.**

Перечень направлений открыт к расширению: новое направление — это запись в
`source/taxonomy.js` плюс манифест актов, без изменения логики платформы.

## Возможности

- **Каталог по направлениям** — видно, какие курсы относятся к вашей работе, с чего
  начать и что рекомендуется изучить дальше.
- **Свободный порядок** — доступ к курсам и уровням не блокируется.
- **Уровни сложности как метка материала:** базовый (знание нормы), продвинутый
  (применение в ситуации), экспертный (спорные случаи и последствия).
- **Поиск** по названиям курсов и уроков, текстам норм, реквизитам актов и
  формулировкам вопросов.
- **Отдельный раздел «Тестирование»** — тренажёр по любой теме в любое время:
  фильтры по направлению, курсу и сложности либо быстрый тест на 10 вопросов.
  Результат не влияет на прохождение курсов.
- **Видеоуроки** — поддержка встроена: у урока есть место под запись, и как только
  появится ссылка, плеер подставится без переделки курса.
- **Разбор ответа** — цитата нормы, реквизиты акта, ссылка на первоисточник и
  кнопка «Оспорить вопрос».

## Цикл корректирующих действий

Ключевая механика — не факт сдачи, а измеримое улучшение:

```
Экзамен курса → Корректирующие действия → Повторный экзамен → Прогресс
```

При неудачной попытке система определяет нормы, по которым допущены ошибки, и
назначает повторение **только соответствующих уроков**. Повторный экзамен
открывается после отметки о выполнении. После пересдачи показывается прирост в
процентных пунктах — он же главная метрика в отчёте руководителя.

## Контроль качества вопросов

Вопросы сгенерированы автоматически из текстов актов. Каждый обязан нести привязку
к норме, иначе не публикуется. После трёх жалоб через кнопку «Оспорить» вопрос
автоматически замораживается и перестаёт выдаваться до разбора.

## Репозиторий

```
index.html        — приложение целиком, один самодостаточный файл
source/           — исходники: контент направлений, таксономия, логика, стили
source/build.sh   — сборка index.html из исходников
SPEC.md           — спецификация полной системы
```

Сборка не требуется для запуска: `index.html` открывается как есть. Прогресс
хранится в localStorage браузера.

## Границы прототипа

Это проверка концепции. Сознательно отсутствуют: серверная часть и учётные записи,
разделение по клиникам, Telegram-напоминания, еженедельный монитор изменений в
«Әділет». Показатели в кабинете руководителя, кроме строки пользователя, —
демонстрационные. Видеозаписи ещё не сняты — реализовано место под них.

## Оговорка

Тексты норм соответствуют состоянию ИПС «Әділет» на дату выгрузки. Материал носит
учебный характер; для юридически значимых решений сверяйтесь с первоисточником по
ссылкам в уроках.
