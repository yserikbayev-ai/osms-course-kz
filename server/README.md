# Серверная версия LMS (этап 1 плана реализации)

Многопользовательская платформа: учётные записи, роли, разделение по клиникам,
прогресс и результаты на сервере.

**Рабочий адрес:** https://lms.refactor.kz

## Состав

```
app/schema.sql   — схема БД: организации, роли, пользователи, контент,
                   попытки, ответы, корректирующие действия, сертификаты, жалобы
app/main.py      — FastAPI: регистрация, вход, каталог, экзамен, тренажёр, отчёт
app/auth.py      — пароли (bcrypt), сессии в БД, cookie
app/db.py        — пул подключений PostgreSQL
app/seed.py      — импорт справочника ролей и учебного контента
static/          — интерфейс: каталог, курсы, уроки, экзамен, тренажёр, кабинет
content.json     — выгрузка контента прототипа для импорта
```

## Развёртывание

```bash
python3 -m venv venv
./venv/bin/pip install fastapi "uvicorn[standard]" "psycopg[binary,pool]" bcrypt
docker run -d --name lms-postgres -e POSTGRES_USER=lms -e POSTGRES_PASSWORD=... \
  -e POSTGRES_DB=lms -p 127.0.0.1:5433:5432 -v /opt/lms/pgdata:/var/lib/postgresql/data postgres:16-alpine
export LMS_DB_DSN=postgresql://lms:...@127.0.0.1:5433/lms
./venv/bin/python -m app.seed content.json      # схема + роли + контент
./venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8011
```

Перед фронтом — reverse proxy с HTTPS (в рабочей установке Caddy).

## Что закрыто из ТЗ

| Раздел ТЗ | Состояние |
|---|---|
| 1. Авторизация и управление пользователями | регистрация, вход, сессии, профиль |
| 15. Расширяемая ролевая модель | 16 ролей в БД, редактируются без правки кода |
| 12. Кабинет организации | отчёт по сотрудникам своей клиники (частично) |
| 8. Тестирование | экзамен и тренажёр на сервере, проверка ответов на бэкенде |

Данные каждой клиники изолированы: пользователь видит только свою организацию.
Правильные ответы не покидают сервер до момента ответа.
