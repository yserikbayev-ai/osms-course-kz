# LMS обучения медперсонала по НПА РК

Рабочий адрес: **https://lms.refactor.kz**

Многопользовательская система управления обучением с персональной траекторией
по должности. Реализованы этапы 1–5 плана по техническому заданию.

## Что умеет

**Учётные записи и роли.** Регистрация с ФИО, телефоном, e-mail, организацией,
должностью и подразделением. 16 ролей в справочнике БД, редактируются без правки
кода. Данные каждой клиники изолированы на уровне запроса.

**Персональная траектория.** Матрица «должность → курсы» задаёт, что назначается
автоматически: обязательное, рекомендуемое, дополнительное и периодическое
обучение со сроком выполнения и периодичностью повторения.

**Личный кабинет.** Проценты прохождения, обязательные и оставшиеся курсы,
ближайшие сроки, блоки «Вам необходимо пройти», «Рекомендуем вам», «Вы уже
прошли», сертификаты и уведомления.

**Каталог и обучение.** Направление → курс → модуль → тема → материалы → тест →
результат. Свободный порядок прохождения, поиск по курсам, темам и текстам норм,
избранное, отдельный раздел тренировочного тестирования.

**Тестирование.** Параметры каждого курса (число вопросов, время, порог, попытки,
перемешивание, срок сертификата) и шкала оценок настраиваются администратором.
Правильные ответы проверяются на сервере и не попадают в браузер.

**Корректирующие действия.** При неудаче назначается повторение только проваленных
тем; пересдача открывается после их выполнения, а прирост между попытками
становится главной метрикой в отчёте руководителя.

**Сертификаты.** Уникальный номер, срок действия, QR-код и публичная страница
проверки подлинности без входа в систему.

**Кабинет организации.** Сотрудники, подразделения, просрочки, отчёт по каждому,
выгрузка CSV, ручное назначение курсов.

**Сводка управления здравоохранения.** Уровень выше организации: область.
Учётная запись управления видит по всем клиникам региона процент обязательного
обучения, сотрудников, не приступивших к обучению, просрочки, прирост после
корректирующих действий, сертификаты и состояние подписки, плюс список курсов с
наибольшим отставанием по области — признак системного пробела. Фамилии
сотрудников управлению не показываются: сводка идёт по организациям. Выгрузка CSV.

Регион заводится администратором платформы (список областей меняется редко,
отдельный интерфейс не нужен):

```sql
INSERT INTO regions(code,title) VALUES ('vko','Восточно-Казахстанская область');
UPDATE organizations SET region_code='vko' WHERE id IN (1,2,3);
UPDATE users SET region_code='vko', is_region_admin=TRUE WHERE email='uz-vko@example.kz';
```

**Уведомления.** Назначение курса, приближение срока, просрочка, результат теста,
выдача и истечение сертификата. Фоновая проверка сроков раз в час.

**Подписки.** Тарифы S/M/L и корпоративный, контроль лимита пользователей при
регистрации, счета, активация после оплаты, автопродление, дополнительные
лицензии, приостановка.

## Состав

```
app/schema.sql, schema2.sql  — схема БД (25 таблиц)
app/schema3.sql              — региональный контур: области и учётка управления
app/main.py                  — регистрация, вход, контент, экзамен, сертификаты
app/api2.py                  — кабинет, траектории, избранное, отчёты, подписки
app/logic.py                 — назначения, статусы, уведомления, подписки
app/seed.py, seed2.py        — контент, роли, матрица должностей, тарифы, шкала
static/                      — интерфейс
```

## Развёртывание

```bash
python3 -m venv venv
./venv/bin/pip install fastapi "uvicorn[standard]" "psycopg[binary,pool]" bcrypt qrcode
docker run -d --name lms-postgres -e POSTGRES_USER=lms -e POSTGRES_PASSWORD=... \
  -e POSTGRES_DB=lms -p 127.0.0.1:5433:5432 -v /opt/lms/pgdata:/var/lib/postgresql/data postgres:16-alpine
export LMS_DB_DSN=postgresql://lms:...@127.0.0.1:5433/lms
./venv/bin/python -m app.seed content.json   # контент
./venv/bin/python -m app.seed2               # роли, матрица, тарифы, шкала, модули
./venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8011
```

## Что осталось за рамками

Загрузка файлов и видео на сервер (сейчас материалы подключаются ссылкой),
уведомления по e-mail и SMS, онлайн-эквайринг (счета выставляются, оплата
подтверждается вручную), типы вопросов кроме одиночного выбора, выгрузка
сертификата в PDF.
