# video/ — видеоуроки по карточкам курса

Remotion-проект, живёт отдельно от сайта: `source/` и `index.html` не трогает.
Один урок = один MP4 1920×1080, 30 fps, 75–90 с. Всё, что на экране, взято из
полей `norm` / `plain` карточек урока в `source/content_*.js` и номеров пунктов.

Сделаны: **L1.2** (81.2 с, 4 круга проверки) и **L1.1** (87.6 с, 2 круга).

## Как собрать следующий урок (L1.3 … L3.x)

```bash
cd video && npm i                      # один раз
cp props/L1.2.story.json props/L1.3.story.json   # и переписать под карточки урока
bash scripts/round.sh L1.3 r1          # props → озвучка → черновик 0.5 → листы кадров
open out/sheets/L1.3-r1-*.png          # смотреть, оценивать, править story
bash scripts/round.sh L1.3 r2          # …пока все сцены ≥9 или оценка не растёт два круга
bash scripts/final.sh L1.3             # 1920×1080 в out/L1.3.mp4 + копия на Drive + лист final
```

Ключ ElevenLabs — `~/.config/elevenlabs/.env` (`ELEVENLABS_API_KEY`,
необязательно `ELEVENLABS_VOICE_ID`; по умолчанию MARIIA_R). Озвучка кэшируется в
`public/audio/<урок>/` по sha1(голос|темп|текст): повторный прогон бесплатен,
пока текст и темп не менялись.

## Что где

| Файл | Зачем |
|---|---|
| `props/<урок>.story.json` | раскадровка: заголовки сцен, элементы, якоря на слова озвучки, итог |
| `props/<урок>.json` | собранные пропсы композиции (генерируется `scripts/props.mjs`) |
| `props/<урок>.check.json` | таблица «текст в кадре → поле урока» и ошибки сверки |
| `scripts/props.mjs` | читает карточки из `../source/content_*.js`, сверяет каждый текст с `norm`/`plain` |
| `scripts/tts.mjs` | ElevenLabs с таймкодами по словам; `openerCut` обрезает заставку |
| `scripts/sheet.py` | листы кадров (кадр на каждый якорь + 0.3 с, плюс плитки 360 px) |
| `scripts/round.sh`, `scripts/final.sh` | один круг проверки / финальный рендер |
| `src/OsmsLesson.tsx` | композиция `OsmsLesson`: заставка, сцена-карточка, итог |
| `src/beats.ts` | тайминг: `T`, якоря `beat()`, раскладка сцен `layout()` |
| `src/theme.ts` | цвета и шрифт сайта (тёмная тема) |

## Формат story.json

```json
{ "lesson": "L1.3",
  "voice": { "card": ["plain"], "opener": "<название>. Приказ … от <дата прописью>.",
             "openerCut": "<последнее слово заставки>.", "summary": "Шесть пунктов приказа. Проверьте себя: N вопросов.",
             "speed": 1.0 },
  "scenes": [ { "header": "…", "peak": true, "items": [ … ] } ],   // ровно столько, сколько карточек, в том же порядке
  "summary": { "lines": ["…" ×6], "cta": "Проверьте себя: N вопросов" } }
```

Элемент сцены: `{id, text, style, tone?, slot, at, out?, strike?, accentAt?, moveTo?, unit?}`.
`style`: `hero` (≥120 px, главный объект), `big`, `text`, `card` (стеклянная карточка),
`label` (46 px), `number` (одометр 300 px + `unit`), `frame` (рамка 1040×380 с подписью).
`tone`: `accent` | `dim`. `slot`: `center | above | below | belowLeft | belowRight | left | right`.
Якоря: `"plain:слово"`, `"plain:слово#2+0.4"` (второе вхождение, сдвиг в секундах),
`"voice:слово"`, `"start"`, `"end+0.3"`. Слово ищется в точной форме, как в тексте озвучки.

## Правила, выученные на L1.2 и L1.1

Содержание
- Каждый текст в кадре — точная подстрока `norm`/`plain` или их сокращение с сохранением
  порядка слов; формы слов не менять (`props.mjs` остановит сборку). Число допускается цифрой.
- Заголовок сцены тоже берётся из нормы. Тире между словами нормы — допустимое сокращение.
- В фокусной группе (без шапки) держать ≤5 слов; предупреждение props.mjs считает вместе с шапкой.
- Итог: ровно шесть строк, по одной на пункт, затем «Проверьте себя: N вопросов», N = число вопросов урока.
- Голос читает `plain` целиком; на экран идёт его сокращение — так полная норма остаётся в субтитрах.

Длительность
- Сумма озвучки + ~14 с (заставка, удержания, итог) = длина ролика. Если `plain` длинные
  (L1.1: 998 символов → 101 с при темпе 1.0), ставить `voice.speed` 1.1–1.15, а не резать текст.
- Заставка: `openerCut` обрезает голос после названия урока, чтобы уложиться в 4 с.
- Удержание итога сцены 1.6 с, финала 3.4 с, наложение сцен 0.5 с (`T` в `src/beats.ts`).

Композиция
- Нулевой кадр не пустой: первая сцена рисуется с `first` (без входного фейда).
- Шапка сцены входит через 0.5 с (когда прошлая сцена ушла) и гаснет до выхода, иначе две шапки видны разом.
- Два элемента в одном слоте в одно время — наложение. Либо `out` у первого, либо `belowLeft`/`belowRight`
  (подходят для коротких карточек, длинные подписи там сталкиваются — класть в `below` с `out`).
- `hero`, уезжающий в `above` через `moveTo`, уменьшается до 0.55 — меньше теряется.
- Одометр докручивается за 0.55 с, чтобы на кадре +0.3 с уже стояла цифра.

Проверка
- Листы кадров смотреть все, включая плитки 360 px (`-phone.png`): там видно, что читается с телефона.
- Оценивать каждую сцену по пяти осям (смысл без звука, композиция, движение, типографика, ритм);
  по стоп-кадрам ось «движение» выше 8 не подтверждается — для неё нужен просмотр видео.
- Не писать «исправлено» без нового рендера и нового листа.

## Сомнения, зафиксированные по ходу

- Ключ ElevenLabs в `~/.config/content-factory/.env` пуст — взят `~/.config/elevenlabs/.env`.
- Субтитры и такты сделаны по таймкодам ElevenLabs, а не через Groq Whisper (точнее и без второго вызова).
- Переходы «камера въезжает в элемент следующей сцены» реализованы как общий push-in/out с размытием,
  а не как непрерывность объекта между сценами.
- Выбрана тёмная тема сайта.
